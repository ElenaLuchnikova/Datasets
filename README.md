# Datasets
В данном репозитории собраны датасеты, которые я использую в своих проектах: https://github.com/ElenaLuchnikova/Analyzes

Подробнее о каждом из датасетов:

* Data_store.csv - данные о продажах небольшого интернет-магазина за 2024-2025 гг.

    Данный датасет содержит информацию о дате покупке, сумме покупки и id пользователя, совершившего покупку. Можно использовать для анализа динамики продаж, когортного анализа, анализа маркетинговых метрик (Retantion, MAU и др.)
* Zara.csv - данные о продажах одного из магазинов сети Zara за 1 квартал 2024 г.
  
    Набор данных включает различные атрибуты, относящиеся к продажам, такие как идентификатор продукта, название продукта, категория продукта, цена, объем продаж, дата продажи и местоположение магазина. Эти данные могут быть использованы для анализа тенденций продаж продукции, показателей продаж в различных товарных категориях, эффективности рекламных акций, моделей покупок клиентами и других факторов, влияющих на показатели продаж Zara.
